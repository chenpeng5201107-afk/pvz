# 植物大战僵尸—函数版：美术素材生成提示词

## 使用方法

以你认可的庭院战斗概念图作为所有素材的风格参考。参考它的手绘线条、草坪质感、色彩、光照和诙谐气氛，不照搬其中错误的加减乘除门、文字、角色数量或棋盘布局。

每次上传参考图，复制下面的「统一风格提示」和某一张素材的「单图提示」。一张一张生成，不要把所有单位拼在同一张图里。尺寸是建议导出尺寸；生成工具不支持时，优先保持宽高比和完整构图，不必强求像素数。

先生成 **01 战斗空场景、04 求导塔、05 对数门**，确认它们放在一起风格统一，再生成其余素材。图片原文件和认可的版本一起交给我；角色尽量保持同一画布、同一脚底位置。

第一版共 26 张基础素材。不需要额外生成十关背景、十张卡牌插画、每个公式对应的敌人或逐帧动画：背景可复用，卡牌和手册可复用角色图，轻微摆动、后坐力、命中、爆炸、冷却和选中效果可由程序完成。

## 统一风格提示：每张都附上

```text
使用我上传的庭院塔防概念图作为美术风格参考，生成同一款游戏中的原创素材。
保持经典 2D 手绘庭院塔防的视觉气质：轻微怪诞、诙谐、有战斗感，夸张但不过度幼态。
深棕黑色的不规则手绘轮廓，清楚的局部明暗，能看见草叶、树皮、旧木板、泥土和纸张的笔触与纹理。主色是草绿、橄榄绿、土褐，少量暗黄、砖红或灰蓝作为点缀；不要粉彩和塑料高光。
世界素材采用参考图的轻微俯视、侧面或四分之三侧面的固定游戏视角，不使用强透视或等距俯视。光源统一来自左上方。界面素材则正面平视，无透视变形。
角色轮廓清楚，缩小到约 90 像素高仍可辨认，细节不要细碎到淹没主体。不要景深模糊、镜头光晕或过量发光。
只继承参考图的美术语言，具体内容以本次单图要求为准。
```

### 通用负面提示

```text
加减乘除标牌，错误数学符号，大段文字，乱码，水印，商标，截图边框，Q版大头，萌系贴纸，马卡龙配色，粉彩，扁平矢量，光滑3D渲染，塑料玩具，日系动漫，写实摄影，血腥，霓虹，过量粒子，角色裁切，多视图，角色拼图，透视不一致
```

不必禁止一切弯曲或几何造型；这里只禁止把 `+ − × ÷` 当成植物的功能标识。

## 图片与程序各自负责什么

- 图片负责手绘外观；角色上的功能符号、敌人公式、关卡名、能量、费用、星数等由程序叠加，不烘焙进图片。
- 当前单位：求导塔 `D`、对数门 `ln`、指数门 `eᵘ`、反正弦门 `arcsin`、正弦门 `sin`、平方门 `u²`、倒数门 `1/u`，以及单格、3×3、整行三档炸弹。这里 `u` 指经过门的函数。
- 没有开根号门；仍有根式敌人，需要用平方门处理。
- 炸弹是种下后等待敌人经过中点触发，不画成已经爆炸或正在投掷的状态。
- 参考图里的割草机不属于当前玩法，不需要生成。暂停提示、按钮文字和五行九列的准确格线由程序绘制。
- 植物与敌人需要真正透明背景 PNG；白底和画出来的灰白棋盘都不是透明。生成工具若不支持透明，可以交付纯色背景原图再处理，但细叶边缘可能需要修整。
- 透明角色不要带地面、大片草坪或投影。接地阴影由程序统一绘制，避免不同素材之间阴影不一致。

## 交付与接入检查

1. 先交前三张试样：战斗背景、求导塔、对数门；确认色调、视角、大小和标牌位置匹配。
2. 再补齐其余角色与界面。每个角色单独一张，不要只交截图或拼图。若不方便按推荐文件名保存，也可以按编号或中文名称标注。
3. 所有公式都留给程序；现有战斗会实时改变敌人表达式，不使用生成图片中的固定 `y=x²` 等文字。
4. 素材收到后再统一修改游戏渲染、登录、大厅、卡牌、手册和弹窗；本文件只准备美术提示词，不改变玩法与数值。
5. 第一版不要求动画帧。如果静态角色的摆动和后坐力效果不够，再基于选定角色补动作，不要现在生成难以对齐的大型动画拼图。
