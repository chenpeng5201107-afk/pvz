# 拼图抠图素材

从用户提供的 1672×941 素材总览中裁切得到，共 26 张 PNG。没有调用图像生成 API，也没有重绘角色。

- 3 张环境素材、10 种我方单位、9 类敌人、4 张通用界面。
- 已去除素材外侧的实色棋盘格、已识别的门洞与肢体空隙背景，以及素材说明文字。
- 白眼睛、浅色衣服、花瓣和空白标牌保留。角色和界面外侧为真实 Alpha 透明背景；登录场景保持不透明。
- 19 张角色统一使用 256×256 透明画布，脚底中心为 `(128, 240)`。这只是统一留白和定位，没有放大原像素；角色实际细节约为原图中的 100–200 像素。
- `manifest.json` 记录原图裁切范围、输出尺寸和实际内容尺寸。公式和运算标识仍应由游戏程序叠加。
- 素材外观照原图保留：单格与范围炸弹仍带引线火星；本次仅抠图，未改变待机造型。
- 本文件夹的战斗背景带有原图已有的格子，草地素材也不保证无缝平铺。实际换肤应优先使用此前单独提取的较大无网格背景 `../handpainted-v1/battle-background.png` 和求导塔。
- 未覆盖此前的较清晰素材，未修改游戏代码或玩法。原始拼图未修改。

全部素材已在深绿、暖褐、灰蓝底色的预览中检查。总览里的角色适合正常游戏尺寸试装，不适合宣传大图或大幅放大。
