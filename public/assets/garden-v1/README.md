# 手绘庭院运行素材

本目录是游戏当前使用的图片，随源码一起保存；运行时不读取开发者的 Downloads 目录，不请求在线图片。Vite 构建时会原样复制到 `dist/assets/garden-v1/`。

- `menu.webp`：用户提供的 2026-09-20 庭院首页图，压缩为 WebP。
- `battle.webp`：已有 `handpainted-v1/battle-background.png` 分区缩放到 1120×624，中央草坪对齐五行九列棋盘；网格与坐标由游戏绘制。
- `unit-*.png`：10 种单位，包含求导塔、6 道变换门和3档炸弹。求导塔和对数门使用用户提供的独立高清图，其余沿用已裁切的手绘拼图素材。
- `enemy-*.png`：9 类僵尸，沿用已裁切的手绘拼图素材。
- `ui-*.png`、`paper.webp`：木质工具栏、按钮、种子卡、纸张面板与纸面纹理。

角色采用 256×256 的 RGBA 透明画布，脚底锚点统一在 y=226。植物标牌中的 `D`、`ln`、`eᵘ`、`arcsin`、`sin`、`u²`、`1/u` 由 `src/game/art.ts` 绘制，不能烘焙为普通加减乘除符号。敌人的实时函数由战斗场景单独绘制，不能写死在图片中。

这些是用户提供的 AI 生成图片及其裁切、去底、缩放衍生素材，不是从原版游戏提取的官方美术；本说明不构成素材版权或商标授权。公开发行或商用前，应确认图片生成服务的使用条款及相关权利。

当前角色使用单张立绘，搭配程序实现的位移、轻微摆动、受击与爆炸效果，不是逐帧行走/攻击动画。
